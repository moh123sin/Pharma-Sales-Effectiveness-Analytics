# Power BI Dashboard Build Guide
Import the CSV files from `data/` or the Excel workbook in this folder. Build these pages:

1. **Executive Summary** - Revenue, Sales Growth %, Incentive Paid, Top Territory, monthly revenue trend, region chart, slicers.
2. **Sales Force Effectiveness** - Rep ranking, calls vs revenue scatter, conversion rate, revenue per call.
3. **Territory Analytics** - Territory performance bars, regional trends, matrix by region and territory.
4. **Incentive Compensation** - Target vs actual, achievement %, performance band, bonus distribution.
5. **Forecasting** - Actual revenue plus `next_quarter_forecast.csv`, and model comparison.

A genuine `.pbix` binary must be created in Power BI Desktop; this repository provides every import file, DAX measure, and page specification required.
